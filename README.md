# redylive para computador

Os instaladores do aplicativo do [redylive](https://redy.lat). Aqui não há
código — só os arquivos publicados e o que o aplicativo lê para se atualizar
sozinho.

## Baixar

**[Pegue a versão mais recente](https://github.com/VoLTz-dll/redylive-app/releases/latest)**

Ou pelo site: [redy.lat/app](https://redy.lat/app).

## O que ele faz que o navegador não faz

**O som do sistema vai junto com a tela, sem eco.** No navegador, transmitir
um jogo em Windows vai mudo: o som só acompanha quando se compartilha uma aba,
que não é o jogo. O aplicativo captura o áudio do sistema deixando o próprio
redylive de fora — sem isso, a voz de todo mundo na sala voltaria para a sala
com atraso.

**Atalhos que funcionam com o jogo em primeiro plano.** `Ctrl+Shift+M` liga e
desliga o microfone; `Ctrl+Shift+A` deixa a janela por cima das outras. Numa
aba do navegador essas teclas nunca chegariam, porque o foco está no jogo.

**Fechar não derruba a chamada.** A janela vai para perto do relógio e você
continua na sala.

## Antes de instalar

O instalador não é assinado, então o Windows mostra *"O Windows protegeu o
computador"* na primeira execução. É o SmartScreen, que avisa isso de todo
programa sem certificado de assinatura de código — que é pago e emitido para
uma entidade identificada. Para seguir: **Mais informações → Executar assim
mesmo**.

A instalação é por usuário e não pede senha de administrador.

## Windows apenas, por enquanto

O áudio do sistema sem eco depende de uma função que só o Windows oferece
(capturar a mistura de som deixando um programa de fora). O resto do site
funciona em qualquer sistema pelo navegador, inclusive no celular.
